# YSoT Platform

Next.js editorial site and admin dashboard for Yaba School of Thought.

## Current Backend

- Firebase Auth for admin login.
- Firestore for articles, authors, categories, gallery items, and events.
- Cloudflare R2 for media uploads.

## Coming Soon

- Newspaper-to-article import automation.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
